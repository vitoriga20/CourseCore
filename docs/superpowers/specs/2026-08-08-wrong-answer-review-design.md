# 错题驱动的今日复习重构方案

## 目标

将知识库从并列展示的错题与数据看板，重构为错题复习的启动页。新用户打开后应立即理解：系统已经从刷题时答错的题目中安排好今天要复习的内容，只需点击即可开始。

## 用户主线

```text
刷题完成 → 总结页标记每道错题的错因 → 错题进入复习队列
→ 今日复习首页 → 开始今日复习 → 直接进入第一道题 → 完成本轮复习
```

## 刷题总结页

- 对每一道答错的题显示错因多选标签；每题至少选择一项才能完成总结。
- 首批标签为：`概念 / 定义没掌握`、`公式 / 定理记不住`、`解题方法不会`、`题型不熟`、`计算过程出错`、`审题遗漏条件`。
- 不提供“就是错了”“粗心”等不能说明复习方向的标签。
- 提交后，题目、错误记录与所选错因一起写入复习队列；一个题目可关联多个错因。

## 今日复习首页

- 页面名称与首屏主题为“今日复习”，不再以“知识库”或统计面板作为首要表达。
- 首屏只设一个强主操作：`开始今日复习`；点击后直接进入系统排在第一位的待复习错题。
- 主按钮旁说明任务来源：系统根据刷题错题安排待巩固题目；不展示预计时长。
- 没有待复习错题时，展示“还没有待复习错题，先去刷题建立你的复习计划”，主操作改为“去刷题”。

## 信息层级与布局

1. **主任务区**：待复习总数、任务来源、开始按钮。
2. **课程筛选**：作为辅助控件，不要求用户先选择课程；默认展示全部待复习错题。
3. **待巩固错题**：使用紧凑的双列或三列卡片，展示题名、题型、错误次数与状态；不再纵向堆叠大卡片。
4. **薄弱点排行**：以紧凑排行展示各错因关联的题量，取代抢占注意力的大型雷达图。
5. **次级入口**：全部错题、查看解析、标记已掌握等操作从属在上述内容中。

## 排序原则

复习队列只由错题构成。排序应优先考虑需要再次巩固的题目，并可将重复错误与关联薄弱点作为排序信号；具体算法在实现前以现有错题与复习数据能力校准，避免虚构时间预估。

## 验收标准

- 初次进入该页的用户能从首屏理解“这是我的错题复习入口”。
- 用户无需挑选题目或课程即可在一次点击后开始复习。
- 每道新产生的错题在完成总结前都要求选择至少一个有效错因，且允许多选。
- 首页不再使用多张并列统计卡或大型图表削弱开始复习的主操作。
- 待巩固错题在常见桌面宽度下以紧凑网格呈现。

## 范围外

- 不新增复习时长估算或倒计时。
- 本轮不重新定义错题优先级算法；仅为后续算法保留并接入错因数据。
