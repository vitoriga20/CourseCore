# 产品需求文档 - CourseCore

## 1. 产品概述

CourseCore 是一个面向大学基础课程（先从大学物理 B（上）起步）的静态化学习平台。核心目标是把课程理论内容、章节训练题、综合测试与期末试卷整合成可离线部署、加载迅速的 Web 应用。

## 2. 核心功能

### 2.1 课程组织
- 课程 → 模块 → 小节三级结构。
- 每个理论小节后跟一个 `type: training` 训练小节，形成“学完即练”的闭环。
- 训练小节与综合测试小节复用同一套 `quizSession` 交互模板。

### 2.2 内容呈现
- 理论内容使用 Markdown 源文件，构建时注入课程数据。
- 训练题/测试题使用 Markdown + YAML frontmatter，支持单选、填空、计算、证明等题型。
- 题目支持题图、LaTeX 公式、标准答案与解析。

### 2.3 答题交互
- 顺序/乱序切换：切换时题号跟随原始题目 ID，乱序使用固定 seed 保证可复现。
- 字体、背景切换：支持几何背景开关、主题切换。
- 提交反馈：inline 训练一次性提交全部题目，逐题显示对错，错题可查看答案，全对后进入下一节。
- 进度持久化：学习进度写入 `localStorage`，答题状态不持久化。

### 2.4 其他页面
- 课程列表、课程详情、知识库、试卷列表、试卷详情。
- 预渲染所有路由，支持直接访问深层链接与刷新。

## 3. 非功能需求

- 构建产物为纯静态文件，可部署到任意静态托管服务。
- 构建流程：`build:training`（PDF 抽取）→ `build:data`（数据生成）→ `vite build` → `prerender.js`。
- 技术栈：Vite 5 + Tailwind CSS 3 + p5.js + 客户端 History API 路由。
- 敏感配置（MinerU token）存放于 `.env.local`，不进入代码仓库。

## 4. 数据与内容规范

- 训练题仅抽取题干，答案字段默认留空，由后续人工补充。
- PDF 抽取使用 `mineru-open-sdk` API，输出 `content_list.json` 与题图。
- 题图复制到 `public/physics/training/<item>/`，Markdown 中 `image` 使用 `/physics/training/<item>/<hash>.jpg`。

## 5. 当前范围

- 已支持：大学物理 B（上）力学 7 章 + 波动光学 6 章，共 13 个训练小节、107 道训练题、291 道总题目、479 条预渲染路由。

## 6. 已知限制

- 训练题答案需人工补充。
- 单选/判断题选中状态在页面重绘后可能丢失。
- LaTeX 依赖 MathJax 异步渲染，极快切换页面时可能出现闪烁。
- MinerU API 对少数希腊符号可能漏识别，当前通过启发式后处理修复。
