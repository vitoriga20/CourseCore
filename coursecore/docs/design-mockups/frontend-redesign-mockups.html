3.2 换元积分法 理论

当被积函数含有复合函数时，可作变量代换 u = φ(x)，将积分化为更简单的形式。第一类换元（凑微分法）：

∫ f(φ(x))·φ′(x) dx = ∫ f(u) du,  u = φ(x)

第二类换元则通过逆向代换 x = ψ(t) 消去根号或化简被积函数，常用于含根式、三角函数的积分。
