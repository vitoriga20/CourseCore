# CourseCore 刷题与知识库优化设计方案

> 版本：V1.0  
> 目标：提升界面美观度、功能完整度、布局规整性、总结页信息密度，以及学习流程中的用户引导。  
> 说明：文档中的设计稿为方向性高保真示意图，重点用于评审信息架构和交互层级。

## 一、设计结论

当前界面已经具备比较完整的功能骨架：刷题首页、试卷预览、组卷、成绩总结、错题库、收藏和社区内容都已出现，深色背景配合绿色主操作色也形成了统一的视觉风格。

但现在各页面更像“功能页面集合”，用户仍然需要自己判断下一步做什么。改版应围绕下面这条学习闭环组织：

```mermaid
flowchart LR
    A[开始学习] --> B[继续上次练习或完成今日任务]
    B --> C[完成题目]
    C --> D[获得成绩与错误原因]
    D --> E[进入错题复习]
    E --> F[查看关联知识点]
    F --> G[练习相似题]
    G --> C
```

核心原则是：每一个页面都要同时回答三个问题。

1. 我现在的学习状态是什么？
2. 哪些内容最值得优先处理？
3. 我下一步应该点击什么？

## 二、现状问题与改版方向

| 问题 | 截图中的表现 | 改版方向 |
| --- | --- | --- |
| 主任务不突出 | 刷题首页的“添加我的试卷”占据大面积，继续练习入口反而不突出 | 首屏优先展示“继续上次练习”和“今日复习” |
| 空白区域较多 | 刷题首页、成绩页、社区页下半屏信息稀疏 | 使用 12 栏栅格，将数据、趋势和行动区重新编排 |
| 总结偏统计 | 目前主要是正确率、题量和错题编号 | 增加知识点、错误原因、用时异常和下一步建议 |
| 雷达图信息有限 | 刷题记录和知识库都使用雷达图，但不容易比较具体差距 | 用排序表、进度条、趋势和可执行按钮替代或补充雷达图 |
| 模块之间割裂 | 错题、知识点、相似题之间缺少明显跳转 | 建立“错题 → 知识点 → 相似题”的双向链接 |
| 内容阅读体验不稳定 | 部分数学公式直接显示 `$...$` 原始语法 | 统一使用数学公式排版，保证题干、选项和解析一致 |
| 状态存在歧义 | 70% 成绩旁出现“良好 ≥75%” | 按成绩动态生成“需巩固 / 掌握良好 / 熟练掌握” |

## 三、全局视觉与布局规范

### 3.1 页面结构

- 页面最大内容宽度：1200–1360px。
- 桌面端使用 12 栏栅格，主内容区间距统一为 24px。
- 左侧导航固定宽度约 224px，内容区自适应。
- 顶部导航高度控制在 64px 左右。
- 页面标题、筛选器、内容卡片、底部行动区保持稳定的垂直节奏。
- 每个页面最多保留 1 个主按钮，其他操作降为次级按钮或文本按钮。

### 3.2 视觉层级

- 背景：深蓝黑色，保持当前产品气质。
- 内容面板：比背景高一个层级，减少过重的卡片感。
- 绿色：只用于主行动、已掌握、进度和成功状态。
- 红色：只用于错误、待复习、风险状态。
- 紫色：用于筛选、题型、辅助信息，不与成功状态混用。
- 次要文字需要提高对比度，避免在深色背景上过灰。

### 3.3 统一组件

建议统一以下组件，而不是每个页面单独设计一套：

- 页面标题区
- 指标卡
- 状态标签
- 筛选器
- 题目卡
- 知识点进度条
- 底部固定行动栏
- 空状态、加载状态、错误状态

## 四、新设计稿

### 4.1 刷题首页

目标：让用户打开页面后先看到“继续什么”和“今天该复习什么”，而不是先看到排行榜或添加试卷。

![刷题首页新设计稿](design-mockups/practice-dashboard.svg)

推荐信息顺序：

1. 继续上次练习
2. 今日复习任务
3. 薄弱知识点
4. 最近练习趋势
5. 我的试卷与按题型练习
6. 社区排行榜等次要内容

首页主卡片建议展示：

- 试卷名称
- 当前进度
- 最近一次练习时间
- 预计剩余时间
- 当前薄弱章节
- “继续刷题”按钮

### 4.2 刷题总结页

目标：从“告诉用户考了多少分”升级为“告诉用户如何提高下一次成绩”。

![刷题总结页新设计稿](design-mockups/practice-summary.svg)

总结页建议分成四层：

#### 第一层：本次表现

- 得分 / 正确率
- 答对题数 / 总题数
- 用时
- 与上次成绩的变化

#### 第二层：问题诊断

- 最薄弱知识点
- 错误原因分布
- 用时异常题
- 按题型表现

#### 第三层：错题清单

每道错题展示题号、知识点、错误原因和复习状态，而不是只展示数字编号。

#### 第四层：下一步行动

- 立即复习错题
- 查看相关知识点
- 练习相似题
- 加入明日复习计划

### 4.3 知识库总览

目标：把知识库从“错题和收藏的存放位置”变成“用户的复习控制台”。

![知识库总览新设计稿](design-mockups/knowledge-overview.svg)

首屏建议展示：

- 今日待复习题数
- 即将遗忘的知识点
- 当前最薄弱的三个章节
- 最近掌握度变化
- 错题、理论、试卷和文章的统一搜索入口

知识点列表建议使用可排序的进度表：

| 知识点 | 掌握度 | 错题数 | 最近复习 | 建议 |
| --- | ---: | ---: | --- | --- |
| 极限与连续 | 42% | 12 | 3 天前 | 立即复习 |
| 导数应用 | 68% | 5 | 昨天 | 练习相似题 |
| 积分 | 86% | 2 | 今天 | 巩固 |

### 4.4 错题复习页

目标：让用户不仅知道“做错了”，还知道“为什么错”和“如何避免再次错”。

![错题复习页新设计稿](design-mockups/error-review.svg)

每道错题应固定包含：

- 题目与选项
- 用户答案
- 正确答案
- 错误原因
- 核心解析
- 关联知识点
- 相似题入口
- 标记为已掌握

选项应该使用整行点击区域，避免截图中 A、B、C、D 选项宽度不一致的问题。

## 五、刷题板块优化方案

### 5.1 刷题首页

将当前“排行榜 + 添加试卷 + 最近练习”的结构改为：

```text
顶部：今日学习目标 / 今日完成进度

左侧：继续上次练习
右侧：今日待复习

中部：薄弱知识点 + 最近成绩趋势

底部：我的试卷 / 按题型练习 / 自定义组卷
```

排行榜可以保留，但移动到社区或个人成就页面。

### 5.2 试卷与题型预览

截图中的试卷预览和题型组卷结构清晰，可以继续增强：

- 显示预计用时和预计难度。
- 显示最近一次成绩和最好成绩。
- 支持按难度、章节、题型筛选。
- 支持随机组卷和保存组卷模板。
- 创建试卷前显示题型比例、题量和预计分数。
- “进入试卷”和“进入练习”统一命名规则。

### 5.3 刷题过程

增加固定的题目工具栏：

- 标记本题
- 收藏
- 查看知识点
- 暂时跳过
- 报告题目问题

答题完成后，不要只显示“正确 / 错误”，还应询问或推断错误原因：

- 概念不清
- 计算错误
- 审题错误
- 方法不熟
- 时间不足

## 六、知识库优化方案

### 6.1 知识库导航

建议将目前的“错题库 / 收藏”扩展为：

- 知识库总览
- 错题复习
- 知识点
- 我的收藏
- 复习计划
- 社区内容

“错题库”和“收藏”可以继续保留为快捷入口，但不应该承担整个知识库的信息架构。

### 6.2 知识点详情页

每个知识点使用固定模板：

1. 一句话结论
2. 核心概念
3. 公式或规则
4. 典型例题
5. 常见错误
6. 易混淆知识点
7. 关联错题
8. 快速自测

这样既能提高阅读效率，也能让社区文章、题目解析和知识卡片使用同一套内容结构。

### 6.3 收藏页

截图中的混合列表方向可保留，但应增加：

- 全局搜索
- 内容类型筛选
- 学科筛选
- 标签和文件夹
- 最近收藏排序
- 批量取消收藏
- 批量加入复习计划

## 七、总结页的信息密度设计

总结页不要只展示静态指标，而要围绕“诊断—行动”组织。

推荐结构：

```text
[本次得分] [答题情况] [用时] [较上次变化]

[知识点掌握度] [错误原因] [题型表现] [用时异常]

[错题 03] [极限与连续] [概念不清] [立即复习]
[错题 07] [导数应用]   [计算错误] [查看解析]

[立即复习错题] [查看知识点] [练习相似题]
```

雷达图可以作为辅助视觉，但不应成为唯一的分析方式。用户需要的是可比较、可解释、可操作的信息。

## 八、以用户为中心的关键流程

### 用户进入产品时

优先显示：

- 继续上次学习
- 今日学习目标
- 今日待复习内容

### 用户刷题时

优先保证：

- 不离开当前页面即可查看解析
- 题目状态自动保存
- 支持跳过和返回
- 清楚区分用户答案与正确答案

### 用户完成练习后

优先提供：

- 成绩变化
- 薄弱知识点
- 错误原因
- 下一步复习动作

### 用户复习知识时

优先提供：

- 关联题目
- 相似题
- 复习间隔
- 掌握度变化
- 快速自测

## 九、功能优先级

### P0：优先修复体验问题

- 修复数学公式渲染。
- 重排刷题首页主任务。
- 增加总结页行动建议。
- 完善错题复习页的答案与解析结构。
- 统一按钮、标签、卡片和间距规范。
- 修复大面积空白和底部孤立区域。

### P1：建立学习闭环

- 错题与知识点双向关联。
- 相似题推荐。
- 按遗忘风险排序。
- 知识点掌握度趋势。
- 收藏页搜索、标签和文件夹。
- 今日学习任务。

### P2：增强产品差异化

- AI 分步解析。
- 根据错误原因生成专项练习。
- 自动生成复习计划。
- 社区内容收藏到知识库。
- 学习成就和排行榜。

## 十、验收标准

改版完成后，可以用以下标准验收：

- 用户进入刷题首页后，3 秒内能找到“继续学习”入口。
- 用户完成一套试卷后，能立即看到至少 3 个可执行的下一步动作。
- 任意一道错题都能跳转到对应知识点。
- 任意一个知识点都能看到关联错题和相似题。
- 总结页首屏同时包含成绩、问题诊断和行动建议。
- 公式、选项、解析在所有页面中均能正确排版。
- 不单独依赖颜色表达正确、错误和待复习状态，状态同时使用文字或图标。
- 页面在 1280px 以上桌面宽度下保持稳定的栅格和内容密度。

## 十一、推荐实施顺序

1. 先修复公式渲染和状态逻辑。
2. 重做刷题首页和总结页的信息层级。
3. 打通错题与知识点的关联。
4. 完善错题复习页的解析和相似题功能。
5. 最后增加社区、排行榜和 AI 能力。

这套顺序可以先解决最影响学习效率的问题，再逐步增加产品丰富度。
