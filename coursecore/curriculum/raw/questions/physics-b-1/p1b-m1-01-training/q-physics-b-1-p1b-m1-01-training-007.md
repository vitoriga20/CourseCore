## Content
一质点在 xoy 平面上运动,运动方程为 $x { = } 3 t { + } 5$ $y = \frac { 1 } { 2 } t ^ { 2 } + 3 t - 4$ 。求以下物理量并把它们表示成直角坐标系中的矢量形式。以时间t为变量,写出质点位置矢量的表示式;
(2)求出t=1s时刻和 $t { = } 2 \mathbf { s }$ 时刻的位置矢量,计算这1秒内质点的位移;
(3)计算t=0s时刻到 $\scriptstyle { t = 4 \mathrm { s } }$ 时刻内的平均速度;
(4)求出质点速度矢量表示式,计算 $\scriptstyle { t = 4 \mathrm { s } }$ 时质点的速度;
(5)计算t=0s到t=4s内质点的平均加速度;
(6)求出质点加速度矢量的表示式,计算t=4s时质点的加速度。
