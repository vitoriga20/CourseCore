# 错题复习主线

- 知识库首页的首要目的为“今日复习”，点击后直接开始系统安排的错题复习，不要求先选课程或题目。
- 刷题总结页必须为每道错题填写至少一个可多选的错因；错因限于可指导复习的原因，禁止“就是错了”等无效标签。
- 错因标签：概念/定义、公式/定理、解题方法、题型熟悉度、计算过程、审题条件。
- 首页用紧凑错题网格与薄弱点排行支撑主任务，避免数据卡片和大型雷达图与开始复习竞争。
