# 物理填空题 / 解答题刷题网页开发计划

## 1. Summary

基于现有 `index（顺序） (3).html` 的交互与样式，新增两个独立刷题页面：

- `index（填空题）.html`：覆盖力学、波动光学的全部填空题。
- `index（解答题）.html`：覆盖力学、波动光学的全部计算/解答题。

题目从当前目录下全部 PDF 练习卷中抽取，保持原题表述不变；由于 PDF 中无答案，需要为每道题自制标准答案并嵌入页面，用于提交后判分与显示正解。

## 2. Current State Analysis

### 2.1 现有文件

- `index（顺序） (3).html`：一个完整可运行的单选刷题页。
  - 技术栈：原生 HTML + Tailwind CSS CDN + MathJax 3 (CHTML)。
  - 交互：顺序出题、底部题号导航、选择/填空两种答题区、答完即锁、绿/红反馈、结果页、重新开始。
  - 数据：题目以 JSON 数组硬编码在脚本中，字段为 `question` / `options` / `answer` / `category` / `type`。
- 16 份 PDF 源文件：
  - 力学：`力学练习一~七.pdf`、`力学综合测试.pdf`
  - 波动光学：`波动光学练习一~六.pdf`、`波动光学综合测试.pdf`

### 2.2 PDF 内容结构（已抽样验证）

每份 PDF 通常包含三类题型：

1. 一、选择题
2. 二、填空题
3. 三、计算题（解答题）

例如：

- `力学综合测试.pdf`：17 道选择 + 15 道填空 + 11 道计算。
- `波动光学综合测试.pdf`：14 道选择 + 10 道填空 + 9 道计算。

### 2.3 已知难点

- PDF 中的数学符号用嵌入式字体编码，直接文本提取会出现大量私有 Unicode 乱码（如 `\uf0f7`），必须人工对照 PDF 视觉内容用 LaTeX 重新排版。
- 填空题答案多为数值/表达式，解答题答案可能包含多问，需要统一答案格式。
- 全部 PDF 题目数量较大，需要“程序提取 + 人工校对/重排”相结合。

### 3.2 第二步：人工重建题库数据

**操作**：

- 对照 PDF 页面，将每道填空题/解答题的题干、待填空白、配图说明（如有）用 LaTeX 重新写成标准数学表达式。
- 为每道题编写标准答案：
  - 填空题：给出最简数值或表达式字符串。
  - 解答题：给出各问最终答案（用分号 `;` 分隔），并附简短推导要点用于错误反馈。
- 统一数据格式示例：

填空题：

```json
{
  "question": "质点的运动方程为 $\\vec{r}=...$，当 $t=2s$ 时，其加速度 $\\vec{a}=$ ________ .",
  "answer": "(..., ...)",
  "category": "力学",
  "type": "fillInTheBlank"
}
```

解答题：

```json
{
  "question": "一升降机内有倾角为 $\\alpha$ 的固定光滑斜面...求 A 对地面的加速度 $\\vec{a}$。",
  "answer": "a = g\\sin\\alpha，方向沿斜面向下；对地加速度为 $\\vec{a}_0 + \\vec{g}\\sin\\alpha$ 的矢量和",
  "category": "力学",
  "type": "problemSolving",
  "solution": "以升降机为非惯性系，加入惯性力 $-m\\vec{a}_0$..."
}
```

**目的**：保证题目与原 PDF 一致，同时获得可判分的答案。

## 4. Assumptions & Decisions

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 输出文件数量 | 2 个独立 HTML | 用户明确要求“两个独立 HTML” |
| 题目来源 | 全部 16 份 PDF 的填空题/解答题 | 用户要求“全部”“完全一致，不改编” |
| 是否显示答案 | 提交前隐藏，答错后显示标准答案 | 符合“刷题”场景，同时满足自制答案需求 |
| 解答题答案形式 | 文本输入，多问用分号分隔 | 保持实现简单，与现有代码一致 |
| 数学公式 | 用 LaTeX 重新排版 | PDF 直接提取的数学符号乱码，必须人工重建 |
| 题目顺序 | 力学在前，波动光学在后，每科内按 PDF 文件名顺序 | 与现有“顺序”页面保持一致 |
| 数据存储 | 继续硬编码在 HTML 内 | 与现有架构一致，无需后端 |
