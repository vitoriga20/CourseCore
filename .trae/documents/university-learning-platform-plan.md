# 大学课程学习平台企划 — CourseCore

## 1. 产品目标

做一个面向大学生的、类似 freeCodeCamp 课程认证体系的在线学习平台原型。

- 先聚焦「课程目录 + 课程详情 + 学习路径」的界面与信息架构，教学内容使用可替换的 JSON 数据，便于后续改造。
- 视觉风格：黑白几何（geometric-design-engineering）+ Apple 极简设计语言。
- 交付物：可运行的单文件 HTML 原型 + 本企划文档。

## 2. 目标用户

- 主要：大一/大二本科生，需要系统学习公共基础课（高数、大物、线代等）。
- 次要：自学者、考研复习者。

## 3. 核心功能

### 3.1 课程认证首页（Landing）

- 平台品牌区：标题、一句话定位、开始学习 CTA。
- 热门/推荐认证课程卡片。
- 今日学习挑战（可扩展）。
- 学习路径总览。

### 3.2 课程详情页（Curriculum）

参考 freeCodeCamp 响应式网页设计认证页面的结构：

- 左侧可折叠课程大纲（模块 → 小节）。
- 主内容区：
  - 课程标题与简介。
  - 完成本课程的要求。
  - 课程模块列表（带进度）。
  - 每个模块展开后显示小节：理论、示例、练习、项目、测验、复习。
- 顶部搜索：全局课程搜索、本课程内搜索。

### 3.3 小节类型

| 类型 | 说明 | 便于改造 |
|------|------|----------|
| 理论 (Theory) | 知识点讲解，支持 LaTeX 公式 | 替换 Markdown/LaTeX 文本即可 |
| 示例 (Example) | 例题分步解析 | 替换题目与步骤 JSON |
| 练习 (Practice) | 小步验证式练习题 | 复用现有刷题页答案判定逻辑 |
| 项目 (Project) | 综合性任务/实验 | 替换项目描述与评分标准 |
| 测验 (Quiz) | 章节测验 | 替换题目 JSON |
| 复习 (Review) | 知识点回顾 | 替换复习内容 |

### 3.4 学习状态

- 未开始 / 进行中 / 已完成。
- 小节级别进度标记。
- 本地 `localStorage` 保存学习进度（无需后端）。

### 3.5 首页双板块

首页改为两个并列入口：

- **学习板块**：课程认证体系，包含 3.1–3.4 的课程目录、详情、路径与进度。
- **知识库板块**：收录所有已做过的题型及其标准解法，按学科/题型/难度组织，支持检索与收藏。

### 3.6 练习与解法

每个「练习」小节不再只是标题，而是包含若干具体题目：

- 题目文本（支持 LaTeX）。
- 题型标签：选择、填空、计算、证明、应用。
- 标准解法：分步解析或视频/文字讲解。
- 用户作答区与判题反馈。

知识库自动汇总用户完成过的练习题型与解法，未做过的题型默认隐藏解法，仅展示目录。

### 3.7 刷题板块

独立刷题入口，覆盖两类题源：

1. **平台题型库**：聚合网页中所有课程的练习题，按学科、章节、题型筛选。
2. **大学期末试卷**：收录真实期末试卷，例如「长沙理工大学 ×× 学院 2025–2026 学年 高等数学（上）期末试卷」，包含试卷结构、题目、答案与解析。

刷题模式支持顺序练习、随机抽题、计时模式（原型阶段可先实现顺序与随机）。

## 4. 课程数据结构设计

使用单文件内嵌 JSON，便于后续替换：

```json
{
  "platform": {
    "name": "CourseCore",
    "tagline": "大学基础课的系统化学习平台"
  },
  "courses": [
    {
      "id": "calculus-1",
      "title": "高等数学（上）",
      "description": "极限、导数、微分、积分与微分方程。",
      "modules": [
        {
          "id": "limits",
          "title": "极限与连续",
          "items": [
            { "id": "l-1", "type": "theory", "title": "数列极限的定义" },
            { "id": "l-2", "type": "example", "title": "用定义证明 lim 1/n = 0" },
            { "id": "l-3", "type": "practice", "title": "计算下列极限" },
            { "id": "l-4", "type": "quiz", "title": "极限与连续小测" }
          ]
        }
      ]
    }
  ]
}
```

### 4.1 练习题数据结构

每个练习小节可挂载题目数组：

```json
{
  "id": "c1-m1-p1",
  "type": "practice",
  "title": "计算基本极限",
  "questions": [
    {
      "id": "q-001",
      "kind": "fill",
      "title": "计算极限",
      "content": "求 $\\lim_{n \\to \\infty} \\frac{1}{n}$。",
      "answer": "0",
      "solution": "当 $n$ 无限增大时，$\\frac{1}{n}$ 无限接近于 0，因此极限为 0。"
    }
  ]
}
```

`kind` 取值：`choice`（选择）、`fill`（填空）、`calc`（计算）、`proof`（证明）、`apply`（应用）。

### 4.2 期末试卷数据结构

```json
{

    {

      "term": "2025–2026 学年第一学期",
      "duration": 120,
      "sections": [
        {
          "title": "一、填空题",
          "questions": [
            { "id": "eq-001", "kind": "fill", "content": "...", "answer": "...", "solution": "..." }
          ]
        }
      ]
    }
  ]
}
```

## 5. 内容规划（示例）

首批规划 4 门认证课程，每门 4-6 个模块：

1. **高等数学（上）** — 极限、导数、微分、不定积分、定积分、微分方程。
2. **大学物理（力学）** — 运动学、牛顿定律、动量、能量、刚体转动、万有引力。
3. **线性代数** — 行列式、矩阵、向量空间、线性方程组、特征值、二次型。
4. **概率论与数理统计** — 随机事件、概率、随机变量、分布、数字特征、大数定律、统计推断。

每门课包含一个「认证项目」作为结课考核（便于后续接入真实题目）。

## 6. 界面规划

### 6.1 页面结构

```
┌─────────────────────────────────────────────────────────────┐
│  顶部导航栏：Logo | 课程搜索 | 主题切换 | 菜单 | 开始学习        │
├──────────┬──────────────────────────────────────────────────┤
│          │  课程标题                                          │
│  左侧    │  课程简介                                          │
│  课程    │  ───────────────────────────────────────────────  │
│  大纲    │  完成要求                                          │
│  (可折叠)│  ───────────────────────────────────────────────  │
│          │  课程模块列表                                       │
│          │  ├── 模块 1                                         │
│          │  │   ├── 理论 1                                     │
│          │  │   ├── 示例 1                                     │
│          │  │   └── 练习 1                                     │
│          │  └── 模块 2 ...                                    │
├──────────┴──────────────────────────────────────────────────┤
│  底部：推荐课程 / 今日挑战 / 页脚链接                              │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 视觉风格

- **色彩**：纯黑 `#000` + 纯白 `#fff` + 灰阶 `#f5f5f5 / #e5e5e5 / #999 / #666 / #333`。
- **字体**：`SF Pro Display / SF Pro Text`（Apple 风格），中文使用 `PingFang SC / Microsoft YaHei` fallback。
- **几何元素**：
  - 页面背景使用 subtle 的黑白几何网格/星芒/透视网格地面（参考 geometric-design-engineering 模式库，但极简化、低对比，避免干扰阅读）。
  - 卡片使用 1px 黑色边框或极淡阴影，保持 Brutalist 与 Apple 极简的平衡。
  - 按钮/标签使用圆角 pill 形状（Apple 风格）或直角几何块（Brutalist 点缀）。
- **动效**：
  - 模块展开/收起：250ms ease-out。
  - 进度条：平滑过渡。
  - 背景几何：极缓慢旋转/漂移，15fps，默认粒子数 0。

### 6.3 响应式

- 桌面：左侧固定大纲，右侧主内容滚动。
- 平板/手机：大纲变为顶部可折叠抽屉或汉堡菜单，主内容全宽。

## 7. 技术方案

- 单文件 HTML，内嵌 CSS + JS + JSON 数据。
- 使用 Tailwind CSS CDN 加速布局（与现有项目一致）。
- 公式渲染：MathJax 3 CDN（预留，当前示例内容可暂不启用）。
- 几何背景：内嵌 Canvas 2D，复用 project_memory 中沉淀的 p5.js 几何球参数（但改为黑白配色）。
- 进度存储：`localStorage`。

## 8. 扩展性设计

- 课程内容完全由 JSON 驱动，后续替换 `COURSES` 数组即可上线新课程。
- 小节类型使用统一的 `type` 字段标记，未来可扩展 `video`、`interactive`、`lab` 等类型。
- 样式使用 CSS 变量集中管理，便于切换主题或品牌色。
- 预留 MathJax 容器，理科课程接入公式无障碍。
