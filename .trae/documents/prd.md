# 产品需求文档 - 物理填空/解答刷题网页

## 1. 产品目标

为物理学习提供两个独立的在线刷题页面：

- **填空题页面**：覆盖力学、波动光学的全部填空题。
- **解答题页面**：覆盖力学、波动光学的全部计算/解答题。

题目内容从当前目录下全部 PDF 练习卷中抽取，保持原题表述不变；由于 PDF 中无答案，需要为每道题自制标准答案并嵌入页面，用于提交后判分与显示正解。

## 2. 页面清单

| 页面 | 文件 | 题目数量 | 题目类型 |
|------|------|----------|----------|
| 填空题刷题页 | `index（填空题）.html` | 60 | 力学 33 + 波动光学 27 |
| 解答题刷题页 | `index（解答题）.html` | 46 | 力学 25 + 波动光学 21 |

## 3. 功能需求

### 3.1 通用功能

- [x] 页面打开后自动加载题目并按顺序显示。
- [x] 题干中的数学公式使用 MathJax 正确渲染。
- [x] 底部题号导航栏可横向滚动，点击题号可跳转。
- [x] 提供"上一题"、"下一题"按钮。
- [x] 提供"完成练习"按钮，点击后显示结果页。
- [x] 结果页显示答对题数、正确率，并提供"重新开始"按钮。
- [x] 重新开始后清空所有答题状态并回到第一题。

### 3.2 填空题页面

- [x] 每道题下方显示单行输入框与"提交答案"按钮。
- [x] 提交后若答案正确，输入框变为绿色。
- [x] 提交后若答案错误，输入框变为红色，并在下方显示正确答案。
- [x] 已提交的题目锁定，不可再次修改。

### 3.3 解答题页面

- [x] 每道题下方显示多行文本框与"提交答案"按钮。
- [x] 提示用户"输入最终答案（多问用分号 ; 隔开）"。
- [x] 提交后若答案正确，输入框变为绿色并提示"回答正确！"。
- [x] 提交后若答案错误，输入框变为红色，显示正确答案与简要思路提示（`solution`）。
- [x] 已提交的题目锁定，不可再次修改。

### 3.4 答案判定规则

- [x] 去除首尾空格。
- [x] 不区分大小写。
- [x] 去除 `$`、`\mathrm{...}`、`\,`、空白、全角标点差异。
- [x] 多空/多问答案统一用 `;` 分隔。

## 4. 题目来源与范围

- 力学：`力学练习一~七.pdf`、`力学综合测试.pdf`
- 波动光学：`波动光学练习一~六.pdf`、`波动光学综合测试.pdf`
- 每份 PDF 包含选择题、填空题、计算题三类；本项目仅抽取填空题与计算题。
- 题目文字保持原 PDF 表述不变；数学公式因 PDF 提取乱码，使用 LaTeX 按原意重建。

## 5. 非功能需求

- [x] 单文件 HTML，无需后端，直接用浏览器打开即可运行。
- [x] 响应式布局，适配桌面与移动端。
- [x] 不改动现有 `index（顺序） (3).html`。
- [x] 样式与交互尽量与 `index（顺序） (3).html` 保持一致。

## 6. 验收标准

- [x] 填空题 HTML 中题目总数为 60。
- [x] 解答题 HTML 中题目总数为 46。
- [x] 每道题的 MathJax 公式都能正常渲染，无乱码。
- [x] 输入正确答案后显示绿色反馈。
- [x] 输入错误答案后显示红色反馈与标准答案。
- [x] 底部题号导航能正确标记已答/对/错状态。
- [x] 完成练习后结果页显示正确题数与正确率。
- [x] 开发文档（development-log.md、technical-architecture.md、prd.md）已更新。

## 7. 已知限制

- 部分题目含"如图所示"，页面未嵌入原 PDF 配图。
- 答案判定基于字符串归一化，不处理数值近似或复杂等价变形。
- 需要网络加载 Tailwind CSS 与 MathJax CDN。
