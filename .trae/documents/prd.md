# 产品需求文档 - CourseCore 大学基础课学习平台

## 1. 产品目标

为大学生提供一个简洁、可部署的大学基础课学习平台，覆盖高等数学、大学物理、线性代数、概率统计等课程。平台以课程学习为主线，辅以知识库沉淀、刷题练习和期末试卷，帮助学生从概念到考题逐步掌握知识。

## 2. 核心功能

| 板块 | 说明 |
|------|------|
| 学习板块 | 按课程 → 模块 → 小节组织学习内容，支持理论、示例、练习、项目、测验、训练、复习等多种小节类型；已上线高等数学（上/下）与大学物理B（上）。 |
| 知识库板块 | 自动收录用户已作答过的题型及其解法，支持按题型分类与搜索。 |
| 刷题板块 | 课程训练题聚合视图，按课程 → 模块 → 小节层级展示题目；支持按学科、题型筛选与搜索，点击题目进入作答页。不再提供全局独立入口，需通过课程或练习列表进入。 |
| 期末试卷 | 收录各高校期末试卷（如长沙理工大学某学院某科目），分节展示题目并支持逐题作答。 |

## 4. 功能需求

### 4.1 通用功能

- [x] 单页应用（SPA），无后端即可运行。
- [x] 响应式布局，适配桌面与移动端。
- [x] 深色/浅色主题切换，状态持久化到 `localStorage`。
- [x] 几何球面网格动态背景，固定参数无 UI 控制。
- [x] LaTeX 数学公式通过 MathJax 3 正确渲染。
- [x] 学习进度、已完成题目、主题偏好保存到 `localStorage`。
- [x] 每个页面对应一个独立 URL（`/`、`/course/:courseId`、`/question/:qid` 等），支持刷新/分享/直接访问。
- [x] 内部导航使用 HTML5 History API，`<a>` 标签可被正常拦截，实现无刷新跳转。
- [x] 全局右上角折叠导航菜单，展开后显示「首页 / 课程（含子菜单）/ 知识库」，支持错位滑入动画与点击外部关闭。
- [x] 构建产物为每条路由预渲染静态 `index.html`，静态托管直接访问子路径不 404。

### 4.2 学习板块

- [x] 首页展示课程列表与学习路径，当前已包含高等数学（上）、高等数学（下）、大学物理B（上）三门课程。
- [x] 课程详情页展示模块与小节，可折叠展开。
- [x] 理论小节内置课程教学内容（Markdown + LaTeX），进入后先展示教学文本，再显示配套训练题；大学物理B（上）理论小节当前为占位内容。
- [x] 测验小节（`type: quiz`）与训练小节（`type: training`）均进入通用测验视图，支持顺序/随机切换（答题状态按题目 ID 跟随，切换模式后当前题保持连续）、衬线/无衬线字体切换、几何/素白背景切换（几何背景使用 p5.js 渲染球面投影网格与十字星星）、题号导航、进度统计与完成报告。
- [x] 训练小节从 PDF 练习册抽取题干生成，答案字段留空由维护者后续补充。
- [x] 每个理论小节末尾必须完成关联训练题，该小节才标记为完成，逻辑与 freeCodeCamp 一致。
- [x] 小节完成状态由训练题完成度自动推导，无需用户手动勾选；测验小节在所有题目作答并完成后标记为完成。
- [x] 练习小节点击进入该小节题目列表。
- [x] 课程可配置学习要求（`requirements`），在课程详情页展示。
- [ ] 侧边栏展示课程列表，支持搜索过滤（已移除：课程入口统一收敛至首页课程卡片与顶部导航）。

### 4.3 知识库板块

- [x] 首页可切换到知识库板块，显示已完成题型数量。
- [x] 首页知识库摘要面板提供"进入知识库"入口，点击进入独立 `/kb` 路由。
- [x] 知识库内容按题型分组展示已完成的题目。
- [x] 支持按关键词搜索已解锁题目。
- [x] 空状态时提示用户先去学习，点击跳转首页学习板块。
- [x] 知识库详情页不再有"返回摘要"按钮，保持独立页面体验。

### 4.4 刷题板块

- [x] 顶部统计卡片展示题目总数、已做题数、正确率。
- [x] 题目按课程 → 模块 → 小节层级分组展示，标题旁显示该小节题目数量与完成进度。
- [x] 支持按学科、题型筛选题目。
- [x] 支持关键词搜索题目。
- [x] 点击小节进入该小节练习列表，点击题目进入作答页。
- [x] 作答后解锁解法并更新学习进度。
- [x] 顶部导航、首页 Hero、知识库空状态不再提供直达刷题页的独立入口，用户需通过课程或练习列表进入。

### 4.5 期末试卷

- [x] 试卷列表展示学校、学院、科目、学期、题数、时长。
- [x] 试卷详情分节展示题目。
- [x] 点击题目进入作答页，作答后返回试卷详情。

### 4.6 题目作答

高等数学（上/下）平台题库已统一为选择题类型（单选/多选/判断），通过 `options` 提供选项并由 `answer` 索引指定正确答案。大学物理B（上）综合测验保留填空题与证明/解答题，允许学生输入表达式或对照参考答案自查；期末试卷仍保留原填空、计算、证明等题型。题目支持可选 `image` 字段展示题图。

- [x] 单选题/判断题点击选项即时判定并显示解法，正确后自动进入下一题。
- [x] 多选题显示 checkbox 选项，点击提交按钮后按集合匹配判定。
- [x] 填空题支持单空或多空，提交后按归一化字符串判定。
- [x] 计算题按数值容差判定，避免浮点精度问题。
- [x] 证明题/简答题提交后显示「人工核对」与参考答案，记录作答但不自动判分。
- [x] 代码题提交后在沙箱中运行测试并反馈结果。
- [x] 答案判定忽略大小写、空白、全角标点、LaTeX 命令差异（填空/简答）。
- [x] 作答后显示反馈区与解法区域，触发 MathJax 重新渲染。
- [x] 题目详情页支持上一题/下一题导航。
- [x] 测验视图（quizSession）内作答时，答对题目立即更新题号导航状态，全部题目完成后显示结果报告并标记小节完成。

## 5. 数据结构

### 5.1 课程

```js
{
  id: 'calculus',
  title: '高等数学',
  description: '...',
  requirements: [
    '完成每个理论小节配套的即时训练题',
    '完成每个模块末尾的综合练习',
    '完成每个模块末尾的测验'
  ],
  modules: [
    {
      id: 'm1',
      title: '极限与连续',
      items: [
        {
          id: 'i1',
          title: '数列极限',
          type: 'theory',
          content: '数列是按自然数编号的一列实数...'  // Markdown + LaTeX 教学文本
        },
        { id: 'i2', title: '函数极限练习', type: 'practice' }
      ]
    }
  ]
}
```

### 5.2 题目

```js
{
  id: 'q001',
  itemId: 'i2',
  courseId: 'calculus',
  moduleId: 'm1',
  questionType: 0,       // questionTypes 枚举值
  title: '极限选择题',
  content: '题干，使用 \( ... \) 表示行内公式',
  options: ['0', '1', '∞'],   // 选择/判断题必填
  answer: '0',           // 单选/判断/填空/计算/代码标准答案
  answers: ['A', 'C'],   // 多选题标准答案集合
  blanks: 2,             // 填空题空位数量
  tolerance: 0.01,       // 计算题数值容差
  unit: 'm/s',           // 计算题单位要求
  solution: '解法说明',
  hint: '提示文本',
  testString: '',        // 代码题验证表达式
  image: '/physics/q006.jpg', // 题图，可选
  difficulty: 1,
  tags: ['极限', '无穷小'],
  source: '力学练习一第3题'
}
```

题型枚举与行为映射：

| questionType | 中文 | 渲染模板 | 验证方式 | 提交方式 |
|--------------|------|----------|----------|----------|
| 0 | 单选 | choice | exact | instant |
| 1 | 多选 | choice | set | button |
| 2 | 填空 | fill | normalized | button |
| 3 | 计算 | calc | tolerance | button |
| 4 | 证明 | calc | manual | button |
| 5 | 判断 | choice | exact | instant |
| 6 | 简答 | fill | normalized | button |
| 7 | 代码 | code | runner | button |
| 8 | 综合 | exam | mixed | button |

## 8. 已知限制

- 高等数学（上/下）已基于同济大学第六版生成真实课程内容；大学物理B（上）理论小节为占位内容，正式讲义待后续补充。
- 平台题库中除大学物理B（上）综合测验保留填空/证明题外，其余非选择题已按规则自动转换为单选题，部分题目的干扰项为程序启发式生成，教学严谨性需后续人工审核与精修。
- 用户进度保存在浏览器 `localStorage`，跨设备不互通。
- 填空/简答题答案判定基于字符串归一化，不处理复杂等价变形。
- 代码题验证当前使用 `new Function()` 沙箱，仅用于内置题目；未来涉及用户可输入代码时必须迁移到 iframe 隔离环境。
- 需要网络加载 MathJax CDN 与 Google Fonts。
