# CourseCore 后台 UI 设计规范

## 1. 设计方向

- **导航结构**：左侧边栏 + 右侧内容区（A 方案）
- **编辑器布局**：左右双栏，左侧编辑、右侧预览（C 方案）
- **视觉风格**：全局深色模式
- **品牌色**：黑底白字 + 墨绿色点缀

## 2. 色彩系统

### 2.1 主色调

| 名称 | 色值 | 用途 |
|---|---|---|
| 背景主色 | `#050505` | 页面背景 |
| 背景次色 | `#0a0a0a` | 卡片、面板背景 |
| 背景三级 | `#111111` | 悬浮、列表项 |
| 边框色 | `#1f1f1f` | 普通边框 |
| 主文字 | `#f5f5f7` | 标题、正文 |
| 次文字 | `#888888` | 辅助说明 |
| 禁用文字 | `#555555` | 占位符、禁用 |

### 2.2 品牌色（墨绿）

| 名称 | 色值 | 用途 |
|---|---|---|
| 墨绿主色 | `#1a3c34` | 选中态背景、边框 |
| 墨绿高亮 | `#4ade80` | 成功提示、选中态文字、图标 |
| 墨绿浅底 | `#0d1f1b` | 选中态浅背景 |

### 2.3 使用规则

- 墨绿色用于：选中态、成功反馈、边框高亮、细微图标
- 墨绿色不用于：普通按钮（除发布/保存等关键操作）
- 普通按钮使用白底黑字或黑底白字

## 3. 侧边导航

### 3.1 结构

侧边栏采用分组折叠：

- **内容管理**
  - 课程
  - 模块/小节
  - 平台题库
  - 理论编辑器
  - 训练编辑器
  - 测试编辑器
  - 期末试卷
- **系统管理**
  - 用户
  - 设置

### 3.2 样式

- 深色背景 `#0a0a0a`
- 分组标题：`#888888`，字号 0.75rem
- 普通项：`#f5f5f7`
- 选中项：背景 `#0d1f1b`，左边框 3px `#1a3c34`，文字 `#4ade80`
- 可折叠/展开

## 4. 理论编辑器

### 4.1 布局

- 整体：左侧编辑区 + 右侧预览区，左右分栏
- 左侧内部：上栏理论正文 Markdown，下栏理论例题
- 例题区：可折叠面板，默认展开第一个，其余收起

### 4.2 理论正文编辑

- 使用 EasyMDE 或纯 Markdown textarea
- 支持 Markdown 语法
- 支持数学公式（MathJax）

### 4.3 例题编辑

- 每个例题一个折叠面板
- 面板内包含：
  - 题干（Markdown）
  - 四个选项输入框（Markdown）
  - 正确答案选择
- 底部有「+ 添加题目」按钮

### 4.4 预览区

- 使用 marked 渲染 Markdown
- 使用 MathJax 渲染公式
- 例题使用 `renderChoice` 渲染交互样式

## 5. 训练 / 测试编辑器

### 5.1 布局

采用三栏结构：

- 左侧：题目列表
- 中间：当前题编辑表单
- 右侧：当前题实时预览

### 5.2 左侧题目列表

- 显示题目序号和题型
- 点击切换当前题
- 拖拽排序
- 底部「+ 添加题目」按钮
- 每道题的删除操作

### 5.3 中间编辑区

- 当前题表单字段
- 根据题型动态切换：单选题 / 填空题
- 支持 Markdown 输入和 MathJax 公式

### 5.4 题型表单

#### 单选题

- 题干（Markdown）
- 四个选项（Markdown）
- 正确答案选择
- 解析（Markdown，可选）

#### 填空题

- 题干（Markdown，含填空占位符）
- 答案输入
- 解析（Markdown，可选）

### 5.5 右侧预览区

- 使用 marked 渲染题干和解析
- 使用 MathJax 渲染公式
- 选择题使用 `renderChoice` 渲染
- 填空题使用 `renderFill` 渲染

## 6. 可复用模块

| 模块 | 用途 |
|---|---|
| EasyMDE | Markdown 编辑器 |
| marked | Markdown → HTML（已依赖） |
| MathJax | 公式渲染（已使用） |
| Split.js | 左右分栏拖拽 |
| SortableJS | 题目列表拖拽排序 |
| renderChoice / renderFill | 题目渲染（已存在） |

## 7. 设计原则

1. 深色沉浸，减少长时间编辑疲劳
2. 墨绿色克制使用，仅作为状态/高亮色
3. 编辑器优先，保证内容创作效率
4. 左侧导航稳定，右侧内容随模块变化
5. 实时预览减少上下文切换
6. 题目列表可快速增删改排序
