## Content
一绕中心轴转动的圆盘,角速度为 ${ \pmb \omega } _ { \pmb _ { \imath } }$ 若将它放在摩擦系数为 水平桌面上,问经过多长时间停下来？(已知圆盘质量为 m 半径为 R,绕轴的转动惯量为 $J = \frac { 1 } { 2 } m R ^ { 2 } \mathbf { \Sigma } )$

## Options
- $\frac { 3 R } { 4 \mu g }$
- $\frac { 5 R } { 4 \mu g }$
- $\frac { 3 \omega } { 4 R \mu g }$
- $\frac { 3 R \omega } { 4 \mu g }$
