## 刷题板块 v1.0 收尾修复（5 期实施完成后的构建修复）

### 修复的 3 个真实 bug

1. **`src/views/practice/index.js` 语法错误（页面白屏）**
   - 症状: `SyntaxError: missing ) after argument list` @ line 1265
   - 根因: 前一轮 Edit 操作产生了 `renderUserRecords` 的**不完整重复块**（line 1241-1261 是被截断的第一份拷贝，1262 才是真正完整的函数定义）
   - 修复: 删除 1241-1261 的孤立片段。文件 1450 → 1429 行
   - **教训**: 大文件里用 Edit 替换长模板字符串块时，old_string 若不够唯一/完整，容易留下半截重复块。改完必须 `node --check <file>` 验证

2. **`src/services/charts.js` 构建失败**
   - 症状: `"DataLabel" is not exported by "node_modules/echarts/components.js"`
   - 根因: echarts 6.x 没有 `DataLabel` 这个 component 导出（label 是内置能力）
   - 修复: 移除 `DataLabel`，改用 `import { LabelLayout } from 'echarts/features'`

3. **路由匹配顺序 bug（发帖页永远打不开）**
   - 症状: `/community/post` 被 `/community/:postId` 抢先匹配，postId='post'，进的是文章详情
   - 根因: `matchRoute` 按 `Object.entries(ROUTES)` **定义顺序**遍历，先匹配先赢
   - 修复: 在 `src/config/routes.js` 把 `communityNew: '/community/post'` 移到 `communityPost: '/community/:postId'` **之前**，并加注释说明
   - **约定**: 本项目 ROUTES 里静态路径必须排在同前缀动态路径之前
