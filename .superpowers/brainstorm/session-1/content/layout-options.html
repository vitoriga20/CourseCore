后台 UI 方向：三选一

基于开源后台的设计语言，选一个最符合 CourseCore 气质的方向

A

侧边导航工作台（参考 Arco Design Pro / Naive UI Admin）

Logo
课程
题目
用户
面包屑 + 内容区（表格 / 卡片）

左侧固定导航，右侧大内容区。适合模块多、需要稳定入口的后台；扩展性好，但会压缩编辑区宽度。

B

顶部 Tab 数据面板（参考 React-Admin-Vite / Next Shadcn Dashboard）

Users | Courses | Modules | Questions | Exams
筛选栏 + 数据表格 + 操作按钮

沿用现有 adminPage 的 Tab 模式，信息密度高，适合以表格为主的 CRUD；但编辑长内容时会显得拥挤。

C

编辑器优先双栏（参考 freeCodeCamp Studio / Notion）

Markdown 编辑
实时预览

以内容编辑为核心，左侧写、右侧看。适合理论和题目编写，但纯表格管理页需要另外设计。

我的建议

CourseCore 后台只有两类高频页面：表格管理页（课程/用户/题目列表）和编辑器页（理论/训练/测试）。 推荐 方案 A 或 B 作为主框架，编辑器页单独走方案 C 的双栏布局。这样既保留统一导航，又保证编辑体验。
