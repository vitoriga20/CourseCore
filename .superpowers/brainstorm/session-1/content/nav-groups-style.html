2. 视觉风格：三选一

A

浅色调黑白极简

白底 + 黑字 + 黑按钮

与现有 CourseCore 前端风格一致，干净、高级、不抢内容焦点。

B

深色侧边 + 浅色内容

侧边
内容

Arco / Naive UI Admin 常见做法，导航更稳，内容区更亮。需要单独维护一套侧边栏暗色变量。

C

全局深色模式

黑底 + 白字 + 白强调色

沉浸式、适合长时间编辑；但白天使用可能疲劳，需确保对比度足够。

我的建议

选 A 浅色调黑白极简。理由：与你现在要求的高端黑白品牌基因一致，且和现有 CourseCore 变量体系完全兼容，实现成本最低。侧边栏可以用浅灰卡片区分，不需要深色。
