右侧详情区：三选一

A

纯编辑表单

右侧只放表单字段，专注编辑。预览单独开 Tab 或弹窗。最简洁，适合初版。

B

上编辑 / 下预览

当前题实时预览，编辑完立刻看到学生视角。信息密度高，适合精细打磨。

C

编辑 / 预览 Tab 切换

编辑
预览

右侧内切换编辑和预览，空间更充裕，但无法同时对照。

我的建议

选 B 上编辑 / 下预览。训练/测试题需要反复看效果，实时预览能省掉很多切换成本。左侧列表提供 + 添加题目 和 删除 按钮，支持拖拽排序。
